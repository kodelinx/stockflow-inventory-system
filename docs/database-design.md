# StockFlow Database Design

## Current Status

Database integration has not started yet.

StockFlow currently starts as a console application. Early versions may use in-memory data and JSON file storage before moving to a database.

## Planned Database Tables

Future tables may include:

- Products
- Orders
- OrderItems
- Payments
- Receipts
- InventoryTransactions
- Users
- Notifications

## Notes

This database design will be updated after the console MVP becomes stable.
