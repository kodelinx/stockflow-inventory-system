# StockFlow Project Overview

## Project Name

StockFlow Inventory System

## Project Description

StockFlow is an inventory and sales management system designed for small business operations. It helps manage products, stock levels, customer orders, payments, receipts, sales income, and business dashboard summaries.

## Project Purpose

The purpose of this project is to build a practical business tool while applying professional software development practices such as requirements gathering, milestone planning, code architecture, version control, documentation, and staged releases.

## Target Users

- Business owner
- Cashier
- Inventory staff
- Admin

## Current Development Stage

Current version: StockFlow v0.1.0  
Current milestone: v0.1.0 Release

## Long-Term Goal

The long-term goal is to evolve StockFlow from a console application into a database-backed business system with API support, dashboard reporting, and deployment-ready structure.
